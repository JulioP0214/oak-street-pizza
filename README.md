# Oak Street Pizza

## Project Description

Oak Street Pizza is an informational website for a fictional pizza restaurant. The website allows customers to learn about the restaurant, view the menu, see restaurant hours, and use a contact form.

## How to Use the Website

Use the navigation bar at the top of the website to move between the Home, Menu, and Contact pages.

- The Home page contains information about the restaurant and its hours.
- The Menu page displays the available pizzas and their prices.
- The Contact page contains restaurant information and a contact form.
